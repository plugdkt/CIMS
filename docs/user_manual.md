# คู่มือผู้ใช้งานระบบ CMIS (คลังวัสดุ/สารเคมี คณะวิทยาศาสตร์การแพทย์ มหาวิทยาลัยพะเยา)

เอกสารนี้อธิบายวิธีใช้งานระบบ CMIS ตามบทบาท (role) ของผู้ใช้แต่ละคน — ระบบจะแสดงเมนูและปุ่มต่าง ๆ
แตกต่างกันไปตามสิทธิ์ที่ผู้ดูแลระบบกำหนดให้ ถ้าเมนูที่ต้องการไม่ปรากฏ แปลว่าบัญชีของท่านยังไม่มีสิทธิ์นั้น
กรุณาติดต่อผู้ดูแลระบบ

## สารบัญ

1. [การเข้าสู่ระบบครั้งแรก](#1-การเข้าสู่ระบบครั้งแรก)
2. [สำหรับนิสิต/เจ้าหน้าที่ (STUDENT / STAFF) — การเบิกวัสดุ](#2-สำหรับนิสิตเจ้าหน้าที่-student--staff--การเบิกวัสดุ)
3. [สำหรับอาจารย์ที่ปรึกษา (ADVISOR) — การอนุมัติใบเบิก](#3-สำหรับอาจารย์ที่ปรึกษา-advisor--การอนุมัติใบเบิก)
4. [สำหรับนักวิทยาศาสตร์ (SCIENTIST)](#4-สำหรับนักวิทยาศาสตร์-scientist)
5. [สำหรับผู้ดูแลคลัง (LAB_MANAGER / AUDITOR)](#5-สำหรับผู้ดูแลคลัง-lab_manager--auditor)
6. [หน้าที่ใช้งานได้ทุกบทบาท](#6-หน้าที่ใช้งานได้ทุกบทบาท)
7. [สิทธิ์ตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)](#7-สิทธิ์ตาม-พรบ-คุ้มครองข้อมูลส่วนบุคคล-pdpa)

## 1. การเข้าสู่ระบบครั้งแรก

1. เข้าเว็บไซต์ระบบ CMIS กดปุ่ม **"เข้าสู่ระบบด้วยบัญชี MEDSCI ACC"**
2. ระบบจะพาไปหน้าล็อกอินกลางของคณะ (MEDSCI ACC) — ล็อกอินด้วยบัญชี UP Account ของมหาวิทยาลัย (บัญชีเดียวกับ
   ที่ใช้ระบบอื่น ๆ ของคณะ) **ไม่ต้องสมัครบัญชีใหม่ และ CMIS ไม่เก็บรหัสผ่านของท่านไว้เลย**
3. ล็อกอินสำเร็จครั้งแรก ท่านจะเจอ **หน้ายืนยันประกาศความเป็นส่วนตัว (Privacy Notice)** — อ่านและกดยอมรับ
   ก่อนใช้งานต่อ (บังคับตาม PDPA ทุกบัญชี ทุกบทบาท)
4. หลังยอมรับแล้ว ถ้าบัญชียังไม่มีสิทธิ์การใช้งาน จะเจอหน้า **"รอผู้ดูแลระบบกำหนดสิทธิ์การใช้งาน"** —
   นี่เป็นเรื่องปกติสำหรับผู้ใช้ใหม่ทุกคน กรุณาติดต่อผู้ดูแลระบบให้กำหนดบทบาท (role) ให้
5. ถ้าบทบาทของท่านคือ **นิสิต/เจ้าหน้าที่ (STUDENT/STAFF)** และยังไม่เคยกรอกข้อมูลส่วนตัว ระบบจะพาไปหน้า
   **"กรอกข้อมูลเพิ่มเติม"** ก่อนสร้างใบเบิกครั้งแรก (สถานภาพ, เบอร์โทร, รหัสนิสิต/รหัสพนักงาน, สาขาวิชา,
   คณะ, และอาจารย์ที่ปรึกษา — จำเป็นเฉพาะนิสิต)

## 2. สำหรับนิสิต/เจ้าหน้าที่ (STUDENT / STAFF) — การเบิกวัสดุ

### 2.1 สร้างใบขอเบิก

1. เมนู **"ใบขอเบิก"** → ปุ่ม **"สร้างใบขอเบิกใหม่"**
2. เลือกห้องปฏิบัติการที่จะเบิก, วัตถุประสงค์ (การเรียนการสอน/งานวิจัย/อื่น ๆ) พร้อมรายละเอียด
3. ข้อมูลผู้เบิก (สถานภาพ, เบอร์โทร, อาจารย์ที่ปรึกษา) จะถูกดึงมาจากโปรไฟล์อัตโนมัติ **แก้ไขในหน้านี้ไม่ได้**
   — ถ้าข้อมูลผิด ต้องไปแก้ที่หน้า "กรอกข้อมูลเพิ่มเติม" ก่อน
4. เพิ่มรายการที่ต้องการเบิก (เลือกสารเคมี/วัสดุ, ปริมาณ, หน่วยนับ) — ระบบจะแสดงยอดคงเหลือปัจจุบันของ
   รายการนั้นให้แบบ real-time ทันทีที่เลือก
5. เพิ่มได้หลายรายการในใบเบิกเดียว กด **"ส่งใบเบิก"** เมื่อครบ (ก่อนส่ง สถานะยังเป็น **"ร่าง"** แก้ไข/ลบ
   รายการได้อิสระ)

### 2.2 สถานะใบเบิกหลังส่ง

| สถานะ | ความหมาย |
|---|---|
| ส่งแล้ว รอพิจารณา | รอผู้ดูแลคลัง (LAB_MANAGER/AUDITOR) พิจารณา (ทุกผู้เบิกรวมนิสิต — ไม่ต้องรออาจารย์ที่ปรึกษา; ใบเบิกของนิสิตจะมีอีเมล/แจ้งเตือนถึงอาจารย์ที่ปรึกษาเพื่อทราบ) |
| อาจารย์ที่ปรึกษาอนุมัติแล้ว | (เฉพาะกรณีที่อาจารย์ที่ปรึกษากดอนุมัติไว้ในใบเบิกของนิสิต) รอผู้ดูแลคลังพิจารณาต่อ |
| อนุมัติแล้ว | ผู้ดูแลคลังเห็นควรให้เบิกแล้ว รอนักวิทยาศาสตร์จ่ายของ |
| ไม่อนุมัติ | ถูกปฏิเสธ (มีเหตุผลแนบมาด้วย) — จบขั้นตอน |
| จ่ายบางส่วนแล้ว / จ่ายครบแล้ว | ได้รับของแล้วบางส่วน/ทั้งหมด |
| ยกเลิกแล้ว | ผู้เบิกยกเลิกเอง (ทำได้เฉพาะสถานะ "ร่าง"/"ส่งแล้ว") |

### 2.3 การรับของจริง (ตอนไปรับที่ห้องปฏิบัติการ)

เมื่อนักวิทยาศาสตร์จ่ายของให้ ท่านเพียงรับของ **ไม่ต้องเซ็นชื่อและไม่ต้องใช้รหัส OTP** (ตั้งแต่ 2026-10-16
นักวิทยาศาสตร์กดปุ่มจ่ายครั้งเดียว ระบบบันทึกผู้จ่าย/ผู้รับ/เวลาไว้ในประวัติการจ่าย)

### 2.4 การคืนวัสดุที่เบิกเกิน/ไม่ได้ใช้

ถ้ามีวัสดุเหลือจากที่เบิกไป ให้นำมาคืนที่ห้องปฏิบัติการ โดย **นักวิทยาศาสตร์ (SCIENTIST) ของสาขาเดียวกับใบเบิก
เป็นผู้บันทึกการคืน** ที่หน้าใบเบิกเดิม (ผู้เบิกบันทึกเองไม่ได้ ต้องคืนใส่ **ภาชนะเดิม** ที่รับมาเท่านั้น) —
ทำได้เมื่อใบเบิกมีสถานะ "จ่ายบางส่วนแล้ว" หรือ "จ่ายครบแล้ว"

### 2.5 พิมพ์เอกสารใบเบิก (F-01)

หน้าใบเบิกแต่ละใบมีปุ่ม **"พิมพ์ PDF"** — พิมพ์ได้ทุกสถานะ (ขั้นที่ยังไม่ถึงจะแสดง "รอพิจารณา" แทนที่ว่าง)
มี QR Code มุมเอกสารสำหรับตรวจสอบความถูกต้องของเอกสาร (สแกนแล้วเปิดหน้าเว็บสาธารณะยืนยันเลขที่/วันที่/สถานะ
โดยไม่ต้องล็อกอิน)

## 3. สำหรับอาจารย์ที่ปรึกษา (ADVISOR) — การอนุมัติใบเบิก

เมื่อนิสิตในความดูแลส่งใบเบิก ท่านจะได้รับอีเมล/แจ้งเตือนเพื่อทราบ **ขั้นของอาจารย์ที่ปรึกษาไม่ใช่ประตูกั้น**
— ผู้ดูแลคลัง (LAB_MANAGER/AUDITOR) พิจารณาใบเบิกได้เลยโดยไม่ต้องรอท่าน แต่ท่านยังกด "อนุมัติ" หรือ
"ไม่อนุมัติ" ได้ขณะใบเบิกยังอยู่สถานะ "ส่งแล้ว รอพิจารณา" (ถ้ากด "ไม่อนุมัติ" ใบเบิกจะจบที่สถานะไม่อนุมัติ)
มี 2 ช่องทาง:

1. **ผ่านระบบโดยตรง**: เมนู "ใบขอเบิก" → เปิดใบที่รอ → กด "อนุมัติ" หรือ "ไม่อนุมัติ" (ต้องระบุเหตุผลถ้าไม่
   อนุมัติ)
2. **ผ่านอีเมล (Signed Link)**: ทันทีที่นิสิตส่งใบเบิก ระบบจะส่งอีเมลพร้อมลิงก์อนุมัติโดยตรง **ไม่ต้อง
   ล็อกอิน** (ลิงก์มีอายุ 72 ชั่วโมง เพื่อความปลอดภัย) — สะดวกเมื่อไม่ได้อยู่หน้าคอมพิวเตอร์

## 4. สำหรับนักวิทยาศาสตร์ (SCIENTIST)

บทบาทนักวิทยาศาสตร์เป็น **บทบาทจ่ายของ** (ปรับเมื่อ 2026-09-21/22): จ่ายของตามใบขอเบิกที่อนุมัติแล้ว,
สร้าง/ดูใบขอเบิกของตนเอง, ดูบัญชีคุมวัสดุและทะเบียนสารเคมี/วัสดุ, และเปิดดูของในคลังกลางสาขา (ไม่เห็นราคา)
**ไม่มีสิทธิ์** พิจารณาใบขอเบิก, รับของเข้าคลัง (GRN), ตรวจนับสต๊อก, ขอทำลาย/ตัดจำหน่าย และดูรายงาน —
งานเหล่านี้เป็นของผู้ดูแลคลัง (LAB_MANAGER/AUDITOR) ดูหัวข้อ 5

### 4.1 การจ่ายของ

1. เปิดใบเบิกที่อนุมัติแล้ว → กด **"จ่ายของ"**
2. ระบบแสดงรายการที่ต้องจ่ายพร้อม**ภาชนะที่แนะนำตามหลัก FEFO** (First-Expired-First-Out — หมดอายุก่อน
   จ่ายก่อน) ให้อัตโนมัติ ไม่ต้องเลือกเองว่าจะหยิบขวดไหน
3. สแกน/พิมพ์ Barcode ภาชนะที่จ่ายจริง กรอกปริมาณที่จ่าย
4. ถ้าจ่ายเกินที่ขอไว้ **เกิน 10%** ระบบจะบังคับให้ระบุผู้ดูแลคลัง (LAB_MANAGER หรือ AUDITOR) ที่อนุมัติการ
   เกินนี้ก่อนจึงจะจ่ายได้
5. กดปุ่มจ่าย — ผู้รับไม่ต้องเซ็นชื่อ/ไม่ต้องใช้ OTP (ดูข้อ 2.3)

## 5. สำหรับผู้ดูแลคลัง (LAB_MANAGER / AUDITOR)

บทบาท LAB_MANAGER (หัวหน้าห้องปฏิบัติการ) และ AUDITOR (ผู้ดูแลคลัง) มี **สิทธิ์เท่ากันทุกประการ** ในงานคลัง:
รับของเข้า, ตรวจนับสต๊อก, ขอและอนุมัติทำลาย, พิจารณาใบขอเบิก, ปรับปรุงยอด, จัดการทะเบียน/ผังจัดเก็บ/คลัง IMS
และดูรายงาน (ทั้งสองบทบาทไม่มีสิทธิ์เข้า Audit Log และตรวจ Hash Chain ซึ่งเป็นของ ADMIN เท่านั้น)
ส่วนผู้ดูแลระบบ (ADMIN) **ในงานคลัง** ทำได้เฉพาะ **รับของเข้า, เปิดรอบ/ดำเนินการตรวจนับ, ขอทำลาย/ตัดจำหน่าย**
และดูแบบอ่านอย่างเดียว (ใบเบิกทั้งหมด, ทะเบียนวัสดุ, คลัง IMS, หน้ารายการปรับปรุงยอด, รายงาน) —
**ไม่มีสิทธิ์** อนุมัติผลตรวจนับ/การทำลาย/ปรับปรุงยอด และนำเข้า/ยืนยัน IMS (ต้องให้ LAB_MANAGER/AUDITOR ทำแทน)
(การยืนยันใบรับของที่ ADMIN ทำได้ จะสร้างแถว "รับเข้า" ในบัญชีคุมทางอ้อม)

### 5.1 การรับวัสดุเข้าคลัง (ใบรับของ / GRN)

(ทำได้โดย LAB_MANAGER, AUDITOR และ ADMIN)

1. เมนู "ใบรับของ (GRN)" → "สร้างใบรับของใหม่" → เลือกห้องปฏิบัติการ, เลขที่ PO/ใบส่งของ (ถ้ามี), ผู้ขาย
2. เพิ่มรายการที่รับเข้า (สารเคมี/วัสดุ, จำนวนภาชนะ, ปริมาณต่อภาชนะ, Lot No., วันหมดอายุ)
3. กด **"ยืนยันรับเข้า"** — หลังยืนยันแล้ว **แก้ไขไม่ได้อีก** (ถ้าผิดต้องยกเลิกทั้งใบแล้วสร้างใหม่ ทำได้
   เฉพาะก่อนยืนยัน)
4. หลังยืนยัน สามารถ **พิมพ์ป้าย Barcode** ได้ทันที (เลือกขนาด 40×25 มม. หรือ 50×30 มม.) ติดที่ภาชนะทุกใบ
   ก่อนนำเข้าจัดเก็บ — Barcode นี้คือกุญแจสำคัญในการเบิก-จ่าย-ตรวจนับทุกขั้นตอนต่อจากนี้

### 5.2 การพิจารณาใบขอเบิก

(ทำได้โดย LAB_MANAGER และ AUDITOR)

เมนู "ใบขอเบิก" → เปิดใบที่รอพิจารณา → กด **"เห็นควรให้เบิก"** หรือ **"ไม่เห็นควรให้เบิก"** (ต้องระบุเหตุผล
ถ้าไม่เห็นควร)

### 5.3 การตรวจนับสต๊อก (Stock Take)

(เปิดรอบและนับได้โดย LAB_MANAGER, AUDITOR และ ADMIN — แต่การ **อนุมัติผลตรวจนับ** ทำได้เฉพาะ LAB_MANAGER/AUDITOR)

1. เมนู "ตรวจนับสต๊อก" → "สร้างรอบตรวจนับใหม่" → เลือกห้องปฏิบัติการ, วันที่ตรวจนับ — ระบบจะสร้างรายการ
   ภาชนะที่ต้องนับให้อัตโนมัติ (ทุกภาชนะที่ยังมีของอยู่ในห้องนั้น)
2. กด **"ไปหน้าสแกน"** — หน้านี้ออกแบบให้ใช้บนมือถือ/แท็บเล็ตสะดวก สแกน Barcode ทีละใบ กรอกยอดนับจริง
3. เมื่อนับครบทุกใบ กด **"ส่งอนุมัติ"** — ผลต่าง (ถ้ามี) จะรอผู้ดูแลคลัง (LAB_MANAGER/AUDITOR) อนุมัติเป็นรายการ
   ปรับยอดอัตโนมัติ (ดู §5.5) โดย **ผู้อนุมัติต้องไม่ใช่ผู้นับรายการที่มีผลต่างนั้น** (ระบบปฏิเสธให้อัตโนมัติ)

### 5.4 การขอและอนุมัติทำลาย/ตัดจำหน่าย

**ขอทำลาย** (LAB_MANAGER, AUDITOR และ ADMIN): เมนู "ทำลาย/ตัดจำหน่าย" → "สร้างคำขอใหม่" → สแกน Barcode ภาชนะ,
ระบุปริมาณ, เหตุผล (หมดอายุ/ปนเปื้อน/ชำรุด-เสียหาย/ของเสีย/อื่น ๆ) → ส่งคำขอ
**รออนุมัติจากผู้ดูแลคลังก่อนจึงจะตัดยอดจริง**

**อนุมัติทำลาย** (เฉพาะ LAB_MANAGER/AUDITOR): เปิดคำขอที่รอ → **"อนุมัติ"** หรือ **"ปฏิเสธ"** —
การทำลาย **ไม่มีการแยกผู้ขอ/ผู้อนุมัติ** (CEO ตัดสิน 2026-09-22) ผู้ดูแลคลังคนเดียวขอและอนุมัติเองได้ ส่วน ADMIN
ขอได้แต่อนุมัติไม่ได้

### 5.5 การอนุมัติปรับปรุงยอด

- **จากผลตรวจนับ**: อนุมัติอัตโนมัติเมื่อกดอนุมัติผลตรวจนับ (§5.3) — ไม่ต้องทำอะไรเพิ่ม
- **ปรับยอดโดยตรง** (เช่น พบของเสียหายนอกรอบตรวจนับ): เมนู "ปรับปรุงยอด" → "สร้างรายการใหม่" → สแกน
  Barcode, เลือกทิศทาง (ปรับเพิ่ม/ปรับลด), ปริมาณ, **เหตุผล (อย่างน้อย 10 ตัวอักษร)**, และเลือกผู้อนุมัติ
  (ต้องเป็นผู้ดูแลคลัง LAB_MANAGER/AUDITOR อีกคนหนึ่ง ไม่ใช่ตัวเอง)

### 5.6 การจัดการทะเบียนสารเคมี/วัสดุและผังจัดเก็บ

- เมนู "ทะเบียนสารเคมี/วัสดุ" — เพิ่ม/แก้ไขรายการสารเคมี พร้อมข้อมูลความปลอดภัย GHS (Hazard/Precautionary
  Statements, สัญลักษณ์อันตราย), แนบเอกสาร SDS (Safety Data Sheet)
- เมนู "ผังจัดเก็บ" — จัดการโครงสร้างที่เก็บ (ชั้น/ตู้/ชั้นวาง) ระบบจะเตือนอัตโนมัติถ้าจัดวางสารที่เข้ากัน
  ไม่ได้ไว้ที่เดียวกัน (เช่น สารออกซิไดซ์กับสารไวไฟ)

### 5.7 การดูรายงาน

(LAB_MANAGER, AUDITOR และ ADMIN)

เมนู "รายงาน" — มีรายงาน 6 ประเภท: สรุปการใช้งาน, รายการใกล้หมดอายุ, รายการต่ำกว่าจุดสั่งซื้อ, รายการที่
ไม่มีการเคลื่อนไหว (Dead Stock), วัตถุควบคุม, และผลต่างจากการตรวจนับ — ส่งออกได้ทั้ง PDF และ Excel

## 6. หน้าที่ใช้งานได้ทุกบทบาท

- **หน้าแรก (Dashboard)**: สรุปภาพรวมตามสิทธิ์ของแต่ละคน (ใบเบิกรอดำเนินการของตนเอง, รายการต่ำกว่าจุด
  สั่งซื้อ, ภาชนะใกล้หมดอายุ — การ์ดหลังจะแสดงเฉพาะผู้มีสิทธิ์ดูรายงาน)
- **การแจ้งเตือน** (ไอคอนกระดิ่งมุมบน): แจ้งเมื่อมีใบเบิกรออนุมัติ, ผลการพิจารณา, สินค้าใกล้หมดอายุ ฯลฯ —
  กด "ทำเครื่องหมายว่าอ่านแล้วทั้งหมด" ได้
- **บัญชีคุมวัสดุ (F-03)**: เปิดจากหน้ารายละเอียดสารเคมีแต่ละตัว → แท็บ "ดูบัญชีคุม" — ประวัติการเคลื่อนไหว
  ทั้งหมดของรายการนั้น กรองตามช่วงวันที่/ประเภทรายการได้ ส่งออก PDF/Excel ได้ (ถ้ารายการมีมากกว่า 5,000
  แถว ระบบจะสร้างไฟล์เบื้องหลังแล้วแจ้งเตือนเมื่อเสร็จ แทนที่จะรอหน้าจอค้าง)

## 7. สิทธิ์ตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)

- เมนูมุมบนขวา (ชื่อบัญชี) → **"ข้อมูลของฉัน"** — ดูข้อมูลส่วนตัวที่ระบบเก็บไว้ทั้งหมด พร้อมปุ่มดาวน์โหลด
  สำเนาข้อมูล (สิทธิ์ในการเข้าถึง/ขอสำเนาข้อมูลตาม PDPA)
- ประกาศความเป็นส่วนตัวฉบับเต็มแสดงให้ยอมรับครั้งแรกตอนล็อกอิน (ข้อ 1) — ถ้าต้องการอ่านซ้ำภายหลัง เข้าที่
  URL `/privacy-notice` โดยตรง (ยังไม่มีลิงก์ตายตัวในเมนูสำหรับเปิดดูซ้ำ ณ ขณะนี้)
